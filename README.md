A one-word answer to the whole internet: `Parasite`.

The internet feeds on its host's attention, copies the host's work, then reposts itself as original content.

The program writes exactly that word to `/output/entry.txt` as UTF-8 text, with no trailing newline and no other output. Set `MAKEFUN_OUTPUT_DIR` to override the destination; an empty or whitespace-only value falls back to `/output`.

Run with Node 22.18 or later:

```sh
node main.ts
```

## Iteration notes

- First pass: `Gossip` — the internet as a rumour mill; funny, fitting, but the most obvious social reading.
- Second pass: `Borrow` — memes, ideas and outrage are all recycled as original content; broader and less predictable.
- Final: `Parasite` — attention is the host, reposts are the life cycle; a sharper joke with the same whole-internet fit.
